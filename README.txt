NOVACART WEBSITE STARTER
========================

WHAT'S INCLUDED
- index.html: the website
- style.css: matte-black and neon-green design
- script.js: product filters and WhatsApp enquiry buttons

IMPORTANT BEFORE PUBLISHING
1. Open script.js in a text editor.
2. Find: const WHATSAPP_NUMBER = "";
3. Put your business WhatsApp number inside the quotes, using international format without + or spaces.
   Nigerian example format: 2348012345678
4. Save the file.

PRODUCTS
The three listings are sample catalogue entries only. They are not confirmed stock or supplier offers.
Before advertising a real item, confirm:
- supplier permission to resell and use product images
- current stock and reseller price
- delivery coverage and delivery cost
- dispatch timing, returns and refund arrangements

HOW TO TEST
- Extract the ZIP file.
- Open index.html in a browser.
- Product filters work locally.
- WhatsApp buttons work only after adding a valid number in script.js.

HOW TO PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository named novacart.
2. Upload index.html, style.css and script.js to the repository root (not inside another folder).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and /(root), then Save.
6. Wait for GitHub Pages to publish and use the URL shown in Settings > Pages.

FREE HOSTING NOTE
GitHub Pages hosts static sites. This starter does not process payments, store customer orders, manage stock, or provide a checkout system. Take orders manually through WhatsApp after confirming all details with the supplier.
